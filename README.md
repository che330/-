# 我的待办清单 (Todo List)

一个简洁美观的待办事项管理网页应用，使用纯前端技术开发，无需后端服务器，打开即用。

## 🎯 项目用途

帮助用户快速记录和管理日常任务，支持：
- 添加新任务
- 标记任务完成/未完成
- 删除任务
- 按状态筛选（全部 / 未完成 / 已完成）
- 一键清除已完成任务
- 数据自动保存在浏览器本地，刷新不丢失

## 💡 设计思路

### 技术选型
- **纯 HTML + CSS + JavaScript**：零依赖、零构建，打开 `index.html` 即可运行，符合"一小时内完成"的轻量项目定位。
- **localStorage 持久化**：使用浏览器原生 localStorage API 存储任务数据，不需要数据库或后端服务。

### 功能设计
1. **输入区**：顶部输入框 + 添加按钮，支持回车快捷添加。
2. **筛选区**：全部 / 未完成 / 已完成 三种视图切换，方便聚焦当前任务。
3. **列表区**：每条任务带复选框和删除按钮，完成的任务显示删除线。
4. **统计区**：底部显示任务总数和完成数，一键清理已完成任务。

### UI 设计
- 渐变紫色背景 + 白色卡片，视觉清新
- 圆角、阴影、动画过渡，提升交互质感
- 响应式布局，手机和电脑都能正常使用

## 🚀 使用方法

1. 直接双击打开 `index.html` 文件即可使用
2. 或者部署到 GitHub Pages / 任意静态文件服务器上访问
